# Scale standard DRAFT (2026-11-18) — for Xavier to approve

Rule: 1 stud = 0.34 m everywhere (our R6 is 5 studs = 1.70 m). Roblox builders size the world for a 5-stud, 4-stud-wide
blocky body, not for real human proportions, so doors and beds are bigger than real life. We follow builder sizes
(what Roblox viewers expect), trimmed where they get silly.

| Thing | Studs | Metres | Why |
|---|---|---|---|
| R6 character | 5.1 tall, 4 wide (shoulders) | 1.70 x 1.36 | our base bodies |
| Ceiling | 10 | 3.4 | real rooms are ~1.4x a person; Roblox builds go 12-16. 10 gives camera room without looking like a hall |
| Door | 4.5 x 7.5 | 1.53 x 2.55 | builders use 7.5-8 tall, 5-6 wide (devforum); a 4-wide body needs the width |
| Seat height | 1.5 | 0.51 | R6 legs stick straight out when sitting; hip pivot sits half a leg above the seat |
| Table / desk top | 2.9-3 | 1.0 | R6 shoulders stay at 3.5 st when seated: hands reach a table at about 3 st |
| Single bed | 5 x 8, mattress top 1.8 | 1.7 x 2.7, top 0.61 | a 4-wide body needs a 5-wide bed; 5 tall + pillow = 8 long |
| Double bed | 8 x 8 | 2.7 x 2.7 | two bodies side by side |
| Nightstand | 2 x 2, 2 tall | 0.68 | top just above mattress |
| Kitchen counter | 3.2 | 1.09 | hands at counter height standing |
| Stairs | 0.6 rise, 1.2 tread, 4.5 wide | 0.2 / 0.41 / 1.53 | readable steps for blocky legs |
| Window sill / height | sill 3, window 4.5 tall | 1.0 / 1.53 | |
| Hand-held prop | about 1 stud on its face | ~0.34 | Xavier: the size of the hand block's square end |

Sources: Roblox devforum door threads (builders use 7.5-8 studs tall, 5-6 wide; the standard Robloxian is 5.125 x 4
studs): https://devforum.roblox.com/t/what-should-be-the-ideal-door-size/2200910 ; a cookbook door reference of
6 x 8 studs: https://subscription-non-live.prod.packtpub.com/book/game-development/9781805121596/6/ch06lvl1sec52/building-out-the-walls

Pulled Creator Store furniture is often bigger still (beds 3.2-4.5 m wide = 9-13 studs): each model gets scaled to this
table when it enters the library. Picture: docs/sheets/scale_v1.jpg.
