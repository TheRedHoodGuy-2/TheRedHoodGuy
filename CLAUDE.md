# TheRedHoodGuy studio: instructions for Claude

Fresh start (2026-11-16). This repo is the STUDIO for the channel theredhoodguy: Roblox-character storytime shorts,
made end to end by Claude with Xavier as the director. The old explainer pipeline lives in
`TheRedHoodGuy-2/explainer-kit` (read-only reference). Nothing from it is binding here unless it is written in this repo.

Xavier wants blunt, short, verdict-first updates. No em dashes. Never a yes-man: if the answer is no, say no and why.

## Start of every chat
1. Read `PLAN.md` (the checklist and where we are) and `docs/DECISIONS.md` (what is settled and why).
2. Read `docs/DIRECTOR_NOTES.md` (every mistake Xavier has flagged; repeating one wastes his time).
3. Read the newest file in `log/sessions/`.
During the chat: a new note from Xavier goes into DIRECTOR_NOTES.md the same turn; research goes into `research/`;
a settled choice goes into DECISIONS.md; the session log gets every message of his and every reply.

## The target: "new video"
Xavier says "new video". Claude: script (FORMAT_BIBLE) -> he approves -> voice generated by Claude -> build ->
automatic gates (every-frame check, clipping check, boredom / hook check) -> low-quality preview -> he approves ->
final render -> title + description -> post. He should never find a mistake Claude could have found.
He accepts 4 to 5 hours per video if it is hands-off.

## Standards (one way of doing each thing, like a studio)
Each standard is a doc that gets written when its checklist item is signed off, then it is law:
`docs/FORMAT_BIBLE.md` (script, hook, pacing, camera), `docs/CHARACTER.md` (base bodies, skin, faces, hair, clothing),
`docs/LOOK.md` (materials, lighting rigs, sets, props), `docs/ANIMATION.md` (posing, motion, clipping),
`docs/PIPELINE.md` (the gates and commands). If a standard does not exist yet, it is not decided: check PLAN.md.

## Hard rules (Xavier's, carried over)
- Never push to GitHub without his OK.
- No music (he adds it). Sound effects only from a real sound bank, never synthesized.
- No cloth folds / crease maps, no impact freezes, no vignette.
- Clipping: near zero. Mild clipping is no longer acceptable.
- Models are real models: imported from a proper source or modelled properly after researching the real object.
  Never stacks of boxes, spheres and cylinders passed off as a prop, a garment or hair.
- Think before every pose, face, prop and camera: how would a real person do it, what do they feel right now,
  can the viewer read the shot. Then check the frames yourself.
- Reference channels are studied for FORMULA (hook, pacing, shot grammar, story shape). Their scripts and shots are
  never republished with our characters. A private calibration remake is allowed and is never posted.

## Where things run
Everything renders in the cloud workspace with Three.js (2 CPU cores, no GPU). See `docs/DECISIONS.md`. Nothing runs on
Xavier's laptop (his only computer, not strong enough); Blender finals wait until he buys one with a graphics card.
